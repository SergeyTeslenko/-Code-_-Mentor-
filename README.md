# КодЛаб — полный сайт

Адаптивный сайт для детской школы программирования.

## Страницы

- `index.html` — главная: Обо мне, Курсы, Методика, Польза, Цены, Калькулятор, FAQ, Запись.
- `python.html` — курс Python: базовая программа из 8 модулей, полная программа
  (5 блоков / 22 модуля / 191 тема с блоком «Проект на Django»), результат обучения и запись.
- `web.html` — курс Web-разработки: базовая программа из 8 модулей, полная программа
  (22 модуля / 139 тем), результат обучения и запись.
- `roblox.html` — курс Roblox Studio: базовая программа из 8 модулей, результат обучения и запись.

## Программы курсов

На страницах `python.html` и `web.html` по две программы:

- **Базовая программа** (`#program`) — 8 простых модулей для детей, карточками.
- **Полная программа** (`#full-program`) — расширенный учебный план аккордеоном
  (`.syllabus` / `.syllabus-item`), модули раскрываются независимо друг от друга:
  Python — 5 блоков, 22 модуля и 191 тема (включая проект на Django),
  Web-разработка — 6 блоков, 22 модуля и 139 тем. Модули сгруппированы классами `.syllabus-block`.

## Программы курсов на главной

В разделе «Курсы» у каждой карточки ссылка «Смотреть программу» раскрывает программу прямо
на странице (блок `.program-fold`). В закрытом виде блок полностью скрыт — под карточками ничего
не занимает места, одновременно может быть открыт только один список.

- **Python** — полная программа: 5 блоков, 22 модуля и 191 тема аккордеоном (`.syllabus`).
- **Web-разработка** — полная программа: 6 блоков, 22 модуля и 139 тем аккордеоном.
- **Roblox Studio** — короткий список базовых модулей (`.program-fold-list`).

Каждый список содержит кнопку, ведущую на страницу курса. Без JavaScript ссылка из карточки просто
ведёт на эту страницу — то есть программа доступна в любом случае.

> ⚠️ Учебные планы дублируются: `index.html` (внутри выпадающих блоков) и страницы курсов
> (`python.html`, `web.html`, разделы `#full-program`). При правке программы меняйте оба места.

## Файлы

- `styles.css` — общие стили всех страниц.
- `script.js` — калькулятор и форма заявки (только главная), окно контактов (все страницы),
  раскрытие программ курсов. Скрипт сам проверяет наличие элементов, поэтому подключается везде.

## Запуск

Откройте `index.html` в браузере или запустите Live Server. Для реальных заявок подключите
обработчик формы в `script.js`.
